# @ylmc2026/popper-compat

Popper-compatible build of `@floating-ui/dom` for the Element Plus zoom
misalignment issue.

Element Plus positions overlays such as dropdowns, popovers, and select menus
with Popper. When the page is scaled with CSS `zoom`, those overlays can shift
away from their anchors. This package replaces `@popperjs/core` with Floating
UI positioning.

## Install

```shell
npm install @popperjs/core@npm:@ylmc2026/popper-compat
```
